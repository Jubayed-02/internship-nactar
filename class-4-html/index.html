Meta & list tags in HTML

Meta tags:

An HTML meta tag is an element used to provide metadata about a web page, which is essentially "data about data". It's a self closing tag, and declared with attributes.

List tags:

There are tags in html which are able to display list.

There are 3 types of list in html:

  1. Ordered list (tag: ol)
  2. Unordered list (tag: ul)
  3. Descripton list (tag: dl)

Ordered list:

The list items will have numeric digits in fornt of them and each list item will be declared in a (tag: li), example:

List of 5 fruits with ordered list:

  1. Grape,
  2. Guava,
  3. Watermelon,
  4. Jackfruit,
  5. Mango.

Unordered list:

The list items will have symbols in front of them and each list item will be declared in a (tag: li), example:

List of 5 flowers with uordered list:

  • Rose,
  • China rose,
  • Lily,
  • Lotus,
  • Sunflower.

Description list:

An HTML description list is a semantic element used to display terms and their corresponding descriptions, definitions, or values in a structured format.

Example of descripton list:

Coffee
Made with milk, sugar and coffee
Tea
Made with milk, sugar and tea leaves
